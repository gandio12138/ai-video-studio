# 视觉与叙事细节补全

## 当前视觉目标与范围
先读CINEMATIC_LOOK.md与PROJECT/STATE的当前视觉设置。cinematic_live_action使用真人电影式单幅目标；完整入口/complete_visual_pack按full_pack，已有内容的风格纠偏按rebuild_cinematic_visuals的calibrate_only，用户明示范围优先。设定板只在用户显式要求时读DESIGN_SHEETS.md并启用；它不替代实际剧情镜头校准。维护或初始化任务不进入创作/媒体执行。


## 输入
为生图提示词补全时先读根目录PROMPT_AUTHORING_STANDARD.md，按初设或保留扩展区分可改范围。补成相连的衣身/袖领/下摆、材质明暗差、结扣及带尾终点、固定空间和动作接触；细节来自当前对象，不能套样例的年龄、服装、戒指或情绪。已显示设计只延续，未显示结构作相容候选，不把扩展变成换装。
先读 AGENTS.md、WORKFLOW_ENTRYPOINTS.md、VISUAL_PRODUCTION.md、PROJECT.md、STATE.md 和用户本轮实际内容。novel_direct 使用原文事实/source_packet；original_script 使用原始创意、人物、大纲/试写稿。没有小说不阻塞原创入口。参考 templates/completion_ledger.md 与 continuity_sheet.md。

## 操作
1. 锁定不可改项、已确认版本、实际覆盖范围；先列视觉和接续缺口，不凭对同名作品的记忆补“原文”。
2. 逐项区分 A视觉、B局部衔接、C核心提案。调用本入口已允许 A/B 草案补全，主动给具体方案，不把普通衣服/发型/布景留成一串待用户填写的问题。
3. cinematic_live_action按CINEMATIC_LOOK.md补衣料重力/受力、真实空间尺度与表演，不把写实等同脏乱或奢华；原时代不因现代风格参考而改变。人物补全要服务时代、身份、财力、性格表现、任务、天气和状态；场景先确定空间再布置道具与光源；服饰写剪裁、层次、材质、配色、鞋履、配件和磨损。实际完整卡交 visual 统一展开，不能另造冲突版本。
4. 事件用“已知起点→必要动作/过渡→已知终点”补齐。记录手、物、位置、视线、门窗状态、情绪外显和可用时长。新增知识、能力、线索、主要人物或因果结果转 C，不假装是无害动作。
5. 需要背景人时写功能、是否出镜/说话、成本，能用既有人物完成则不新增；novel_direct 不新增对白或隐藏关键剧情。
6. 为每条补充给 CMP 编号、类别、依据、方案、人物适配理由、受影响资产/镜头、状态。B 的事件计入动作与时间表；不能只列在报告却不让下游采用，或只出现在生图正文里。
7. A/B 可进入本轮草稿：A source_packet 用明确“制作补充”列/段落；B 原创剧本新草稿用来源记录关联。源文件和已确认稿不覆盖。C 未批准依入口规则留提案或明示临时试写。
8. 交 shots/visual 后回查：镜头需求如果发现设计缺口，先更新同一补全台账/卡，再更新提示词，不每镜随机补。

## 输出与验收
01_story/EP01_completion_ledger_vNN.md；03_shots/EP01_continuity_vNN.md；相关内容依据新草稿及变更摘要。已有版本递增，更新 STATE 的草稿进度，不自动 G1/G2。
检查：是否主动填具体细节；是否能解释为什么符合此人此地；是否仅用最小补充解决接续；有没有新增秘密/能力/关系；是否影响声音与镜长；是否真实标注来源。不声称已生成图片或审美已被实图验证。
