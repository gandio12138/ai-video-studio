# 关键帧与图像任务执行预留

先遵守根目录 AGENTS.md；路径相对项目根目录。


## 输入
已确认视觉设定、05_prompts、04_visual/assets.json、providers 配置、相关批准。提示词设计用 manju-prompts，视觉决策用 manju-visual。
## 步骤
1. 先生成/导入一个角色和一个场景的小样，确认后再展开。每任务绑定角色/服装/场景版本与实际参考图 SHA-256。
2. 使用 templates/image_job.json 与 job.json。外部调用须预算、输入上传许可、有效适配器与参数能力核实；否则 status=planned，返回阻塞。
3. 多参考说明每张用途，局部编辑记录区域、目标和保持项。参考文件缺失时不虚构路径、不声称已经看到。
4. 实际图像落地后检查尺寸、可打开性、构图、身份、手/道具、连续性。没有视觉工具时把目检标待人工，不以文件存在替代验收。
5. 原图不覆盖；采用图与拒绝 take 分开，更新资产登记和下游依赖。镜头关键帧与角色定妆参考是不同资产。
## 输出
06_assets/generated 内实际图片（仅真正生成/导入后）；04_visual/assets.json 的真实状态；07_reviews/image_review_vNN.md；任务与哈希。
