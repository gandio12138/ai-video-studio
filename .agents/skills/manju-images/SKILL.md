# 关键帧与图像任务执行预留

## 当前视觉目标与范围
先读CINEMATIC_LOOK.md与PROJECT/STATE的当前视觉设置。cinematic_live_action使用真人电影式单幅目标；完整入口/complete_visual_pack按full_pack，已有内容的风格纠偏按rebuild_cinematic_visuals的calibrate_only，用户明示范围优先。设定板只在用户显式要求时读DESIGN_SHEETS.md并启用；它不替代实际剧情镜头校准。维护或初始化任务不进入创作/媒体执行。


先遵守根目录 AGENTS.md；路径相对项目根目录。


## 输入
编写、改写或执行生图提示词前先读根目录PROMPT_AUTHORING_STANDARD.md，核对任务模式、完整正文与可见验收点。发现正文缺连续结构、参考用途或明确目标时交manju-prompts补齐，不能压缩成几个标签提交；用户明确要求原文直用的正文保留原样，冲突单列。新角色、新场景及后续集数同样适用；这不新增工具能力或费用权限。
已确认视觉设定、05_prompts、04_visual/assets.json、providers 配置、相关批准。提示词设计用 manju-prompts，视觉决策用 manju-visual。
## 步骤
1. 按本轮明确授权的范围生成/导入；电影式校准可先身份/衣装主图、空景，再以真实采用参考做已有动作/互动单幅。单个资产/编辑请求不扩成三图或整集，母图请求按下方两路执行。先实际查看对应图的观感、人物适配与空间接触，再决定后续批次；无授权只准备任务。每任务绑定角色/服装/场景版本与实际参考图 SHA-256。
2. 使用 templates/image_job.json 与 job.json。外部调用须预算、输入上传许可、有效适配器与参数能力核实；否则 status=planned，返回阻塞。
3. 多参考说明每张用途、固定/排除项与未知补全；执行前实际查看并传入所需图片，提示词中写文件名不等于工具收到附件。局部编辑记录真实底图、版本、区域/行列、实际问题、目标和保持项；条件式预案不能直接当已就绪修正。参考文件缺失时不虚构路径、不声称已经看到；允许无图的初设任务。
4. 实际图像落地后先按CINEMATIC_LOOK.md核对真人拍摄观感、衣料/皮肤、表演与接触遮挡，再检查尺寸、可打开性、构图、身份、手/道具、连续性。没有视觉工具时把目检标待人工，不以文件存在替代验收。
5. 原图不覆盖；采用图与拒绝 take 分开，更新资产登记和下游依赖。镜头关键帧与角色定妆参考是不同资产。
## 输出
06_assets/generated 内实际图片（仅真正生成/导入后）；04_visual/assets.json 的真实状态；07_reviews/image_review_vNN.md；任务与哈希。

## 可选设定板执行边界
仅显式要求设定板的批次才读DESIGN_SHEETS.md并执行本节；仍需独立媒体授权。区分concept_sheet整板探索、production_sheet的单图生成与排版，以及剧情关键帧。相关说明放人读manifest，不向旧严格job/image_job契约随意加字段。
可用一张采用正面图直接生成整板候选并逐格检查；也可复用获准主图、派生独立图，审核后再拼版。两路不强制互换，无需先齐备侧背/胸像才允许整板；背面未知结构只作相容候选。合格源可重复用于多个版块但只按真实任务记账。每格检查脸/衣装/身体比例、场景地标与光源，整板漂亮不等于所有格通过；逐格通过且用户采用后才记录相应批准，不永久把整板路线限制为不能采用。
保持独立原图、实际尺寸、哈希与真实裁切来源；小格放大不能宣称找回真实细节。纯拼版只做等比放置、批准裁切、标签/图示，不让生成模型重绘全部素材。
本包尚无拼版程序或生成API；未接入记unconfigured。用户指定可用工具并授权后方可执行，不自动安装。导入用户版式参考不能当作角色已经生成。
角色或场景源图变化追踪具体下游；仅改板上标签不使全部镜头失效。剧情图不带板的文字、格线、色卡或重复角色。
