# 图像参考与局部编辑提示词

## 输入
读 AGENTS.md、PROJECT.md、STATE.md、已确认视觉设定和目标镜头；参考 templates/prompt_job.md。检查 04_visual/assets.json 与用户实际提供的图片；确认目标工具/模型是否已指定。

## 步骤
1. 分清任务是新建角色定妆、空场景、道具、参考合成、镜头静帧还是局部编辑。写任务编号、关联镜号/资产与所需输入。
2. 按附件顺序列每张参考图的用途：身份、服装、布局、风格、待编辑底图。缺图时标“缺少输入”，可写条件式草案，不声称已应用参考。
3. 使用具体主体、固定外观、动作瞬间、场景、景别/角度/构图、光线/风格、保留项与输出需求。风格与身份描述引用确认版，不能随机加饰品或改服装。
4. 镜头构图写前中后景、人物画面位置、视线方向、主体大小与裁切；字幕区域按当前平台约束，否则标临时安全区。重要文字优先后期添加。
5. 局部编辑写底图、精确区域、唯一改动、必须保留的身份/姿态/背景/光线、验收清单；蒙版需求与格式以选定工具文档为准。不保证非目标像素完全不变。
6. 模型未知时只给通用自然语言。不要自动加某平台的 --ar、seed、权重或 negative_prompt 字段；若用户要求模型适配，先核实该模型当前支持什么，再列参数与来源。不把生成镜头表 JSON 当成模型 API 参数。
7. 默认中文，不自动附冗长英文；用户需要时再给含义一致的英文版。每次迭代只改必要变量，并记录修订点。
8. 自检冲突：近景却要求全身、正面却要背面、单角色却写群像、左右混用、深夜却正午主光、局部修改却整体换风格；发现则先修提示词。

## 输出
05_prompts/C001_design_v01.md、L001_scene_v01.md、EP01_SH001_v01.md 或 edit_JOB001_v01.md。每份分“参考输入”“可复制提示词”“约束”“后期”“验收”，标状态 prompt_only。
不要声称实际图片已生成、已上传或已保存，除非已调用有权限的工具并核实真实结果。需要实际生图时另请用户授权并确认预算/工具可用性。

## v2 生产交接
实际图像执行交 manju-images，动态镜头任务交 manju-video；生成提示词不代表媒体已存在。参考文件哈希属于缓存输入。
