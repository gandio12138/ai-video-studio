# 详细图像提示词与覆盖交付

## 输入
读AGENTS.md、PROJECT.md、STATE.md、VISUAL_PRODUCTION.md和templates/prompt_job.md。读采用或明示试作的内容/镜头、STYLE、人物/衣装/场景/道具卡、CMP台账与assets。G1/G2未批准不阻塞授权草稿，媒体执行仍需另批。

## 方法
1. 按本轮所有角色/场景/关键道具/镜头建立任务矩阵；每独立角色五类、每地点三类、每镜至少一条、人物和场景各一类编辑预案。必要远景群体例外要说明。禁止只示范头两镜或只列任务不写正文。
2. 主定妆与空景主图可文生图；侧背/表情/反角/合成标参考依赖。参考不存在时路径null/awaiting_reference，不伪造上传；完整条件式正文照写。
3. 每条按模板写管理信息、参考输入、独立可复制正文、约束、后期与验收。来源/CMP/版本留在管理区，不用编号取代正文，也不让复制正文依赖另一个未提供的文件。
4. 正文展开画面可见的年龄观感/脸发/身形/衣装剪裁材质配色、姿势、左右手和道具、视线、场景结构、景别/机位/前中后景、光源方向和冷暖、具体画风。特写只展开可见细节，不机械粘整套鞋背设定。
5. 细节服务叙事与人物，避免统一华服、同一张脸、无意义粒子与装饰；不混互斥风格；定妆看得清，镜头关键帧不是时装摆拍。正文不留“同上、C001+L001、{服装待填}”。
6. 静态图只描绘一个确定瞬间；复杂动作回交shots/enrich分解，不在一张图要求进门/落座/递物全过程。反角沿固定空间坐标换算画面左右。
7. 局部编辑必须单一区域/单一目标、保持身份/姿势/背景的具体项、允许必要光影衔接；没见结果只写条件式预案，不声称已发现或修复错误，不保证逐像素锁定。
8. 模型未知用通用中文自然语言，画幅是构图意图；不硬加seed/权重/负面字段/蒙版规则。确需特定模型适配再查当前官方文档，未核实项留空而非猜测。
9. 与镜头/设计/CMP台账做逐项比对，写templates/visual_pack_index.md索引：真实文件#任务标题、依赖、状态、角色/场景/镜头覆盖数字及明确缺项。执行工具可用时查文件存在，但不把存在性当内容质量通过。

## 输出
05_prompts/characters/C001_vNN.md（五条分标题）、locations/L001_vNN.md（三条）、props/P001_vNN.md、shots/EP01_SH001_vNN.md（逐镜）、edits/EP01_edit_recipes_vNN.md、EP01_visual_pack_index_vNN.md。同类可集合，但正文需逐条完整，索引可定位。
全部prompt_only；若设计未确认另记draft。缺参考标awaiting_reference，不改成任务failed。实际执行交manju-images或manju-video，绝不声称文字文件就是已生成图片。
