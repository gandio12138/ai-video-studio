# 逐镜视频任务与连续性

## 当前视觉目标与范围
先读CINEMATIC_LOOK.md与PROJECT/STATE的当前视觉设置。cinematic_live_action使用真人电影式单幅目标；完整入口/complete_visual_pack按full_pack，已有内容的风格纠偏按rebuild_cinematic_visuals的calibrate_only，用户明示范围优先。设定板只在用户显式要求时读DESIGN_SHEETS.md并启用；它不替代实际剧情镜头校准。维护或初始化任务不进入创作/媒体执行。


先遵守根目录 AGENTS.md；路径相对项目根目录。


## 输入
已确认关键帧、镜头表、实际音频/有声分镜、模型能力与批次授权。读 video_job.json。
## 步骤
1. 每镜选择静帧保持/后期运镜/图生视频/其他实际素材。生成动作写主体、动作幅度、镜头运动、终点状态，不给单镜塞多个跳时。
2. 区分生成档位时长、实际返回时长、剪辑采用时长。服务未选时 generation_duration_s=null。首尾帧、多参考、seed、原生音频、续拍只按所选模型真实能力使用。
3. 非必要不强求正面长对白口型；lipsync 独立能力未接入，不能自动宣称对嘴。使用原生声音时检查与已确认台词/声音的一致性，禁止直接混进正式音轨。
4. 批次先做单镜样片，确认后提交。异步任务保留远端 ID，超时先查状态与费用，不重复创建。
5. 实际落地后 probe 规格/时长，保存原件与候选 take；按CINEMATIC_LOOK.md查看真人电影式观感是否在动作中保持，检查身体受力/接触/表演、人脸/衣装/道具、机位、运动、边缘、闪烁、接续、可采用区间。没有看过视频则标未目检。
6. 无法用的镜头先最小修改或静帧替代，重试受批次上限约束。剪辑采用区间不能超过实际素材。
## 输出
09_video/jobs/、09_video/clips/、资产登记、逐镜审查和取用入点。视频工作流 JSON 与本包任务单不是同一格式。

## 单幅首帧与可选参考板
电影式视频使用已验收的单幅剧情关键帧；只有需要板资料时读DESIGN_SHEETS.md。多格角色/场景设定板可作参考资料，不默认直接当视频首帧；先生成/选取已验收的单幅剧情关键帧。核对不存在格线、标签、色卡、重复展示人物。
场景布局、人物衣装状态和实际镜头一致；工具不支持相关多参考时报告，不假称可把所有板同时喂入。能力仍以真实已接入工具为准。
