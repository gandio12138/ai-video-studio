# 角色定妆与场景设定

## 输入
读 AGENTS.md、PROJECT.md、STATE.md，人物表、剧本/镜头需求与 04_visual/assets.json。参考 templates/visual_bible.md。只使用实际提供的参考图，不能因看见文件名就声称知道图像内容。

## 步骤
1. 提取原文确定外观与场景事实；没有写明的设计列为创作补充，等待确认。原稿身份/道具线索不得被美化修改抹去。
2. 写统一风格的可操作描述：线条、色彩、阴影、材质、比例、背景复杂度、光向；不要用“高级感、电影感”取代具体设计。
3. 每个角色固定少量识别锚点：脸型、眼型、瞳色、发型发色、体型、标志物；分开固定身份、衣装版本与表情姿势。区分角色自身左右和画面左右。
4. 先规划一张主定妆参考确认，再派生全身/侧面/背面/表情，不把多张无关联的文生图称为同一角色一致性方案。
5. 每场景固定门窗、家具、通道、光源相对关系，用文字平面图描述常用机位/轴线；空景主图与必要反角分别规划。
6. 道具写尺寸参照、形状、材质、状态与持有人。重要纸条/屏幕文字写成后期准确文本。
7. 更新 asset 条目而非换号；只有真实生成文件存在才写 path，并在人工确认后改 approved。视觉方案改变时提示相关镜头和提示词待复核。

## 输出
04_visual/visual_bible_v01.md；必要时分 characters_v01.md、locations_v01.md、props_v01.md；更新资产计划与参考图任务清单。
此阶段默认只写文字和任务需求。最后列需要用户确认的主角色/场景方案，交 manju-prompts 写生成任务单。

## v2 生产交接
把采用视觉参考的版本和哈希交 manju-images；人物视觉定妆与 manju-voice 的声音定妆分别确认。
