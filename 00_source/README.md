# 原稿目录（只读）

已有小说：把自己创作或有权使用的片段保存为 UTF-8 的 TXT 或 Markdown，例如 `chapter_001.txt`。第一轮先提供 1500–3000 字左右的连续片段，或一章；这只是便于人工复核的试作建议，不是工具限制。
只上传你愿意发送给所用 AI 服务的内容，不放合同隐私、密钥或无关私人文件。
若资料特别长，先让 manju-story 建章节索引并分批分析；每批注明读取范围和未覆盖章节。不要把一次片段分析当作全书审校。

没有小说：在 PROJECT.md 指定“原创”，先做一句话梗概、人物目标和章节大纲；选定后再按需写第一章，不必先写完长篇。

不要让 AI 改写这里的原始文件。改编与新稿都放 01_story 或 02_scripts。
