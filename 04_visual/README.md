# 视觉设计
按VISUAL_PRODUCTION.md写STYLE与characters/、locations/、props/详细卡，使用CMP台账统一补充。
生图相关设计先读PROMPT_AUTHORING_STANDARD.md。详细卡解释连续衣装/结构、材料区别、空间左右和参考边界；人物/场景按当前镜头需要交主参考及必要视角，不固定五类/三类。交prompts展开每条完整正文与可见验收，新人物新地点同样适用。asset为planned时path=null，不把文字设计当真实图片。
