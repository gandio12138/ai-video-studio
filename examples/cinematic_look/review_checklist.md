# 样张对照验收

本表是美术工作约定，不是自动评分器。没有真实图片时每项标未检查。
建议先比较同一用途：人物近景对照参考近景，空景对照环境镜头，不拿全身正面图与强戏剧近景只比“谁更美”。

| 维度 | 检查问题 | 常见修正方向 |
|---|---|---|
| 风格 | 是否仍像动漫、厚涂、游戏/手办？ | 检查真正送入模型的正文、模型适配与风格参考；删除互斥风格，而非继续加华丽形容词 |
| 人物 | 是否符合已给年龄、身份、世界和审美，而非统一娃娃脸？ | 单独校准身份主参考和衣装，不能一边扩镜一边换脸 |
| 材质 | 衣服有受力褶皱吗？皮肤自然还是过度磨皮/蜡感？ | 只补当前尺度可见的材料信息，优先修局部或主参考 |
| 场景 | 是否像可走进去的地方，尺度、家具接地和通道合理？ | 固定布局主图，纠正局部比例，不新增无用装饰 |
| 光 | 光从哪里来？脸、衣料和背景是否属于同一灯光状态？ | 保留明确主光和可解释辅光，避免矛盾光源 |
| 表演 | 人物在行动/反应，还是所有图都直视镜头摆拍？ | 明确目标、对手方向、手部任务、视线与重心 |
| 镜头 | 焦点、景别、前景遮挡与负空间是否服务这句剧情？ | 一次只改构图或表演等一个主变量，避免全项乱改 |
| 连续性 | 正反打的衣装、道具、门窗、视线接得上吗？ | 核对固定卡和站位，不把镜像当换机位 |
| 画内杂物 | 是否有UI、字幕乱码、拼格、身份标签、水印或重复主角？ | 写清输出用途，选择干净参考；不能将参考裁片当正式底图直接发布 |

记录：样张路径 / 提示词版本 / 实际模型与参数来源 / 已上传参考 / 查看者 / 具体问题 / 最小修改 / 用户采用依据。
将“文件存在、分辨率正确”和“视觉已通过”分开。不能把提示词与图片的长短/数量当成效果证据。

依赖能力尚未知时，暂不推荐特定模型、权重或采样参数。实测需记录用户实际在用的工具及失败图片；不能仅凭本视频承诺某提示词一定同等效果。
