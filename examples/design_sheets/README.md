# 角色/场景设定板文字示例
本例只演示一名角色C001和一处场景L001的板与单格提示词。教学情节沿用“雨夜信使递湿信”，外貌、服装、空间尺寸、画风细化均为独立教学分支的制作提案，不是用户正式故事或原文事实。
实际人物图、场景图、参考图、布局图、整板都没有生成。只有包内用户上传的版式参考真实存在，不能用它当林岑身份参考。
worked_prompts.md给整板提示词与可复制单格正文；location_layout.md给空间/机位。没有把未绘制示意写成PNG。examples未经指定不得作为正式项目输入。
本例不覆盖守夜人角色、不交全集分镜，因此不冒充完整首集视觉包；正式完整入口仍按实际出镜人物和镜头全覆盖。
