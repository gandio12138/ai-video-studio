# 从一句话到可生图的细节｜原创教学片段，不是完整集

实际源：同目录source.md的[P001]。以下未在原句明说的外观、空间、表演均为本例制作提案，状态draft。没有参考图、没有实际生图，不用于正式项目。

## 1. 先锁住事实

雨夜；林岑是信使；他走进驿站，把湿信递给守夜人；守夜人读信后让他先别走。
不能为了画面好看把湿信设计成干燥信封，也不能把“先别走”擅自解释成暗杀/亲属相认。

注意CMP005里取信并不能把原文的湿信变干；边角应暗湿、柔软，字样后期处理。递信完成后信在守夜人手里，下一镜不能又回信使手中。

## 3. 美术方向提案

偏写实比例的二维漫剧插画，外轮廓干净、细节线条克制，阴影以清楚块面组织，木/布/皮有轻微纹理但不过度锐化。画面以青灰和木褐为主，油灯暖黄作少量焦点；雨夜的冷光用于区分人物轮廓。角色定妆用均匀光确认造型，故事画面才加入冷暖冲突。

## 4. 林岑半身主定妆提示词（无参考初始设计稿）

```text
为架空山地驿站故事设计一张单人男性信使的半身主定妆参考图。人物22岁，偏瘦而有耐力，肩背结实但不夸张，狭长脸、平直深眉、深棕眼睛，鼻梁线条自然，嘴唇轻抿，下颌略收，神情警觉但不过分凶狠。黑发在后脑低束，额角几缕短碎发，脸上不添加伤疤或神秘纹样。
穿青灰色窄袖短交领外衣，粗织棉麻表面低反光，领口露出一小段暖灰内搭，袖口有使用后磨软的纤维边缘；深苔色无纹样雨披搭在双肩，系带朴素，没有金属胸甲、金饰和家族徽章。雨披与发梢略湿，但不遮挡脸部、领口和肩部轮廓。
单人正面偏四分之三半身，姿态自然，双肩与全部发型清晰可见；浅暖灰无图案背景，柔和均匀侧前方照明，面部不过曝，无强烈逆光遮脸。偏写实比例的二维漫剧插画，干净轮廓线、克制块面阴影，布料和湿雨披的材质区别清楚。青灰为主、暖灰和深苔为辅，整体简洁耐看，不做贵族时装海报。
只画一个人，不拼多视图，不加文字或水印。
```

## 5. 驿站空景主视角提示词（无参考初始设计稿）

```text
一张架空山地驿站的雨夜室内空场景设计图，9:16竖幅，偏写实比例的二维漫剧插画。空间狭长，南墙是入口，北侧是一条低矮旧木柜台，东墙只有一扇小窗。机位在南门内侧偏西，朝北略偏东看，主要建立柜台、窗口与中间步行通道的关系，不为了画面丰富新增侧门。
前景下沿露出一小段被雨鞋踏湿的深灰粗石地面，石缝和潮湿反光克制；中景中央保持清楚的行走与递信区域，不摆挡路桌椅；后景旧木柜台水平展开，柜面边角磨圆，后墙灰泥有修补色差，只放少量实际使用的杯碗，不堆满装饰。梁柱是暗木色，结构清晰，不做宫殿雕花。
柜台东端一盏油灯是暖主光，在本机位画面偏右，暖光集中照亮递信区域与柜面木纹。东墙小窗透入微弱冷青夜光，雨迹在窗外，不让室内满屏雨点。画面以木褐、灰石和青灰为主，暖黄只作叙事焦点，远处细节简化，明暗有层次但关键区域可读。
不出现人物，不增加神秘符号或新线索；门窗柜台位置须供后续镜头继续沿用，底图不绘制字幕和准确招牌文字。
```

反向机位应从北侧柜台后看向南门，东窗会出现在与主视角不同的画面侧；世界位置不变。这是换机位，不是把房间左右镜像或再加一盏灯。

## 7. 单一区域修改预案

```text
仅在实际成图的信纸错误地显得干燥时，编辑两人手之间的信纸区域。将纸边改为被雨水浸湿后略深的颜色、轻微软化起伏；保留双方手指姿态、脸、衣装、柜台、窗和整体构图。不增加印章、文字或撕裂，不改变故事信息。允许信纸边缘接触阴影做必要变化；其他区域保持原设计。未提供实际底图时不要执行或声称已经修复。
```
