# EP01 开场场景剧本｜30 秒示例
状态：draft；来源：source.md P001–P006；未经用户确认。

## SC01｜L001 修理铺｜内｜夜
林夏在柜台内，林舟在柜台外。旧表在林夏手边。空间说明属于视觉补充。

### B01｜建立关系与遗物
林夏把旧表放到柜台，手指停在表边；林舟站在对面。时钟滴答。
来源：P001。

### B02｜卖表提议
林舟将当票推来。
林舟：“卖了，够交三个月房租。”
来源：P002。

### B03｜疑点
林夏拿起旧表，翻看表壳的新撬痕，抬眼盯住林舟。
林夏：“你动过它？”
林舟避开目光。
来源：P003–P004。

### B04｜发现纸片
林夏翻开松动的双层后盖，从盖板夹层取出折纸，展开。
纸张摩擦声。
来源：P004–P005。

### B05｜文字揭示
纸条特写，后期叠入准确文字：“林舟不是你哥哥。”
无旁白，给观众阅读时间。
来源：P005。

### B06｜出口关闭
林舟举着刚按下的遥控器，抬眼看林夏。画外卷帘声。
林舟：“爸还写了什么？”
来源：P006；以画外声音代替完整卷帘下降画面，是低成本视听改编，不改变事件。

## 对白处理
原句已经较短，保真版保留，不为追求压缩比例丢掉“三个月房租”这一处境信息。
“你动过它？”必须保留“动过”的追问含义，不改成无因果的“为什么？”

## 连续性
旧表：柜台 → 林夏手中 → 打开后盖，留在柜台。
纸片：盖板夹层 → 林夏手中 → 仍在林夏手中。
遥控器：林舟右侧衣袋 → 林舟手中。
当票始终留在柜台，不随切镜消失。
