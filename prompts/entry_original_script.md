# 入口 B｜没有小说：从设定、人物与概述创作剧本

不必先写小说。把已有想法填进代码块，零散也可以；或让 Codex 读取本文件，再在消息中给出输入。空白并不一律构成阻塞。

```text
$manju-producer

读取 AGENTS.md、WORKFLOW_ENTRYPOINTS.md、PROJECT.md、STATE.md、
CAPABILITIES.md 与 config/runtime.json。
本轮选择 entry_mode: original_script。
我没有小说，直接开发原创漫剧剧本，不把缺少原稿列为阻塞。

【我的输入】
世界/背景设定：[几句话即可]
人物描述与关系：[名字、性格、关系、想做的事，知道多少写多少]
简短故事概述：[可以不完整，也可以没有结局]
想要的类型/感觉：[例如悬疑、温暖、喜剧]
必须保留的内容：[填写；没有则写暂无]
不希望出现的内容：[填写；没有则写暂无]
首集时长与制作限制：[填写；未填沿用 PROJECT 的确认值]

【入口与补充原则】
记录本入口，不重置已有作品进度；与旧故事冲突先问，不混入旧小说。
保留我的原始输入，区分“用户给定”“AI补充提案”“待决定”。
不得擅改我指定的身份、关系、世界规则和结局要求。
一般空白可合理补充并集中列出，不要求我先写专业策划案。
影响核心方向的空白最多给两个方案，可按明确标注的推荐临时方案试写，
不能偷偷定稿。真正无法继续才提问，一次最多三个。
只使用本项目本轮指定资料；不把 examples 或未指定小说当事实来源。
我已给出方向时直接发展，不反复要求我重新选题。

【本轮执行】
依次使用 manju-story、manju-script、manju-audit 的工作方法。
我明确授权本轮在大纲未批准前试写第一集，全部标 draft，
不必每完成一个小文件都停下来问，但不等于获得 G1 批准。

1. 原创设定简报：保存原始输入，写一句话故事、核心规则、
   系列长期矛盾简述、必须保留项及 AI 补充提案。
2. 人物表：长期欲望、本集具体目标、阻力、失败代价、
   主动行动、行动后果、人物关系、知道什么、说话特点。
   不用“聪明、冷酷”这种标签代替目标与动机。
3. 第一集大纲：按清晰叙事节拍写起因、行动、对抗、变化与结束状态。
   首集围绕一个主要冲突，不塞入全部世界观和人物。
   结尾可留悬念，但本集必须有实际进展，反转不能破坏因果。
4. 第一集剧本试写：场次、地点、可见动作、对白、旁白、必要音效。
   把心理尽量转为动作、选择和反应，不重复解说同一信息。
   人物、场次、台词给稳定编号，表演指导与可朗读文本分开。
   同步输出逐句台词表，按 templates/line_sheet.json。
5. 剧情检查：检查因果、动机、信息来源、设定一致性、对白和时长。
   给具体位置、证据、影响、最小修复；不只评分或夸奖。
   重大改动先提案，未经确认不把检查建议自动写成最终设定。

时长只估算并标“待朗读/配音校准”。
制作参数未确认时，可临时按60秒、2名主要出镜角色、1个主要场景试写，
明确这只是首集建议；与我的硬设定冲突先说明，不偷偷删人物。
不为固定时长让台词不自然，也不为增加冲突强行让人物降智。

【保存与停点】
按递增版本输出：
01_story/story_bible_vNN.md
01_story/characters_vNN.md
01_story/episode_outline_vNN.md
02_scripts/EP01_vNN.md
02_scripts/EP01_lines_vNN.json
07_reviews/EP01_script_review_vNN.md
集号按实际项目替换，沿用现有模板，不覆盖已确认文件。
更新 STATE，所有本轮新稿为 draft；缺少小说为 not_required_by_mode。

本轮不写长篇小说、不展开全季、不拆正式镜头表，
不生图、不配音、不生成视频、不渲染、不安装依赖、不调用付费接口。
在首集试写与检查完成后停止，最多给我三个关键决策点。
等我明确确认具体剧本和台词版本，再进入文字分镜与制作。
```
