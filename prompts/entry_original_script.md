# 入口 B｜没有小说：原创剧本、细节补全、分镜与视觉提示词一并开发

用户给几个设定、人物描述、一段概述就可以开始，不先写小说。首轮不是只写剧本：还要做详细人物/场景设计和可复制生图提示词。全部可先是明确标为draft的文字方案，等待实际采用。

```text
$manju-producer

读取 AGENTS.md、WORKFLOW_ENTRYPOINTS.md、VISUAL_PRODUCTION.md、
PROJECT.md、STATE.md、CAPABILITIES.md 与 config/runtime.json。
本轮 entry_mode: original_script；visual_pack_required: true；
completion_policy: visual_and_local_bridge_draft。
这些是文字工作约定，不自动更改媒体权限。

【我的输入】
世界/背景设定：[几句话即可]
人物描述与关系：[姓名、身份、性格、关系，想到多少写多少]
简短故事概述：[可不完整，可没有结局]
类型与情绪：[例如悬疑、温暖、喜剧]
画风与审美偏好：[没有则按故事给一个具体推荐草案]
必须保留的内容：[无则写暂无]
不希望出现的内容：[无则写暂无]
首集时长、画幅、角色和场景限制：[未填沿用PROJECT确认值]

【工作方式】
我没有小说，直接开发原创剧本，不索要EPUB，不先写小说或全季。
保留我的原始输入，区分用户给定、AI补充、待决定。
不要混入旧改编项目、examples或未指定的小说；不重置已存在的进度。
我给出方向后直接发展，不反复让我重新选题。

我授权你在首集草案中主动补齐人物行动、局部事件和转场，
以及人物外貌、服饰、场景、道具、光线、表演等未写明的细节。
不要求我先补完专业策划案，也不把普通空白全部变成问题。
按VISUAL_PRODUCTION.md建CMP补全台账，说明设计如何服务人物与故事。
原创新剧情可以在我的设定范围内发展；
核心空白最多给两个方案，可用明确标注的推荐临时方案试写，
但不能擅自改掉我已经指定的身份、关系、规则和结局要求。
真正无法继续时才提问，一次最多三个。

【完整首集文字批次】
依次采用manju-story、manju-script、manju-enrich、manju-audit、
manju-visual、manju-shots、manju-prompts的方法；需要时局部迭代。
我明确授权同一批次试写未确认大纲、试拆未确认剧本，
并据此做视觉设计和生图提示词草案。
这些都保持draft/prompt_only，不等于用户批准，不直接生成媒体。

1. 保存原创简报、人物关系与目标：
   一句话故事、核心规则、主角本集可失败目标、阻力、代价、
   主动选择与行动后果，人物分别知道什么、如何得知。
2. 写首集大纲与场景剧本：
   起因→行动→对抗/变化→结局状态；本集有进展而不是只铺世界观。
   动作、对白、旁白、音效分开，人物/场次/台词编号稳定。
   同步逐句台词表，区分spoken_text、direction和subtitle_text。
   原创对白可以打磨压缩，但不丢因果、角色语气与重要信息。
3. 主动补全并落实到草稿：
   人物的外貌、体态、发型、动作习惯；服装的层次/剪裁/材质/
   配色/鞋履/配件/旧损；场景结构/家具/光源/活动区；
   道具出现、拿取、交接，以及进出场、情绪转换和场间过渡。
   不只说“需要补充”，要把具体方案写出来。
   新人物/事件必须有功能，不用巧合或人物突然降智填漏洞。
4. 剧情检查：
   定位因果、目标、信息来源、对白、时长问题，给最小修复。
   重大待定项明确标注，不拿AI检查代替用户采用。
5. 建统一美术方向、角色/场景/道具详细卡，试拆文字分镜：
   景别、机位、动作、台词、音效、时长、素材、衣装状态、
   原始设定/剧本/CMP依据和起止连续性都写清。
   一个静态关键帧只描绘一个具体瞬间。

【美术与生图提示词：必交，不放到“以后再做”】
美感靠人物适配、轮廓、剪裁、配色主次、材质对比、空间层次和光线，
不是一堆“绝美、高清、8K、电影感”。
穷人不自动穿金甲，老人不美化成年轻脸；角色之间要有辨识差异。
画风未选时先给一个适配推荐稿，不阻塞全部设计。

每个独立识别角色：详细定妆/衣装卡 + 半身主参考、全身正面、
侧面、背面、关键表情五类独立提示词。
每个场景：详细布局/材质/光源卡 + 空景主视角、
反向/替代机位、剧情关键区域三类独立提示词。
关键道具：独立提示词；没有则注明不适用。
每个镜头：一条完整可复制静态关键帧提示词，不仅示范头几镜。
局部修改：至少人物和场景各一种单一区域的条件式修正预案。

每条正文展开实际可见的人物身份/外貌/衣装、姿势/视线/哪只手持物、
场景材质、景别/构图、主光方向与统一画风。
不要只写编号、同上、套模板或未填括号。
初始主参考可文生图；派生任务需要的参考图尚不存在时写null和前置任务，
标awaiting_reference并给完整条件式正文，不谎称已上传。
模型未指定时写通用中文自然语言，不乱加接口参数。

【时长与范围】
时长只估算，待实际朗读/配音校准。补充动作和停顿计入镜长。
参数未确认时可以暂按60秒、9:16、2名主要出镜角色和1个主要场景提出首集草案，
但与我的硬设定冲突时先说明，不偷偷删除必要人物或挤掉因果。
只做本轮首集，不扩写全季。

【交付】
01_story/story_bible_vNN.md、characters_vNN.md、episode_outline_vNN.md
01_story/EP01_completion_ledger_vNN.md
02_scripts/EP01_vNN.md及EP01_lines_vNN.json
03_shots/EP01_shots_vNN.json及同版.md、EP01_continuity_vNN.md

05_prompts/EP01_visual_pack_index_vNN.md
07_reviews/EP01_script_review_vNN.md
07_reviews/EP01_visual_continuity_review_vNN.md

按VISUAL_PRODUCTION.md核对任务覆盖、细节具体性、人物适配、
图文设定一致、空间动作与时长接续；填写真实已输出文件和仍缺项。
已有版本递增，不覆盖；更新STATE但不自动标G1/G2通过。
没有小说记not_required_by_mode，缺生成模型不阻塞提示词。

本轮只做上述文字工作，不生图/配音/生成视频、不渲染、
不安装依赖、不调用付费接口。
“不生图”不等于不写提示词；提示词写好不等于真实图片存在。
完成后停止，列实际交付与最多三个关键决定。
```
