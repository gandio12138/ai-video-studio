# 样例依据与新增规则的区分

两份示例均由用户提供，完整原文保留，不修订其中的角色、用词、结构、历史操作或复核记录。

## 来源支持的方法

### 正面全身样例

`C001_V04_FRONT_cand01.prompt.txt`

- “参考图使用边界”区分保留身份与授权废除旧衣结构。
- 人物呈现及“配色和材质”将脸、发束、三层明度和不同材料分别描述。
- 外层、中层、腰部、长裤、靴子逐部位交代覆盖、连接、长度、轮廓和细节。
- “古戒连续性”区分角色自身左右、画面左右、具体指位、数量及不能添加内容。
- “构图”“画风与照明”“最终必须一眼清楚看到”给出实际可见的要求。
- “袖子与裤腿局部修正提示词”独立限定目标部位及保持项。

### 母图样例

`C001_V02_CHARACTER_SHEET.prompt.txt`

- 唯一图片参考可以作为整板生成起点，不要求第二胸像或预先存在的侧背。
- 三行布局明确格数、比例、同一人物尺度、允许文字与细节分区。
- 固定身份、头部朝向、发型、衣装、关键物，逐视角说明真实左右与遮挡。
- 五个表情写具体眉眼唇变化，区别视线降低和整个头部下低。
- “表情局部修正提示词”定位两个格子并保持其他格与版式。
- 原文期望输出尺寸与历史实际输出尺寸不同，记录时不应混淆。

## 本包新增的通用工作规则

- 跨人物、跨场景、跨集数和所有入口的持久适用范围与引用方式。
- 原创无参考、授权重设计、造型保留扩展、同空间扩展、局部编辑的任务分支。
- 对小说未写明细节的补全权限、提案登记、剧情影响边界。
- 场景建筑、固定布局、材质和机位；场景母图默认布局；道具与关键帧模板。
- 语言、工具能力、付费授权、文件保留、未执行不能冒充完成等执行约束。
- 文本级合并检查与通用任务回归项目。

这些是为了本项目后续应用新增的建议，不声称两份人物示例包含全部内容，也不承诺仅靠规范就能保证实际图像一致性或达到样例效果。
