## 正向提示词（独立可复制，填成正文）
按共享标准第4节组织：目标与输出 → 参考边界 → 主体身份/状态 → 连续结构与比例 → 材质/明度差 → 关键物位置与遮挡 → 机位/表演或逐格任务 → 光照背景 → 针对性排除 → 可见验收。按画面所需展开具体正文，不将这条组织提纲当成交付。
single_panel/shot任务：用途和画幅 → 一个明确瞬间 → 画面可见人物的身份/外貌/衣装细节 → 身体动作/自身左右手/持物/视线 → 场景可见结构与材质 → 景别、机位和前中后景 → 真实光源方向、冷暖/软硬与视觉焦点 → 具体统一画风。

sheet_concept任务：完整角色/空间设计 → 各区版式与逐格用途/具体内容 → 统一锚点与约束；多格可以展示同一人物的不同视角，不表示多个剧情人物。assembly_plan只写真实源图取用与布局，不要求重绘。

不保留“{主角外貌}”“同上”“C001+L001”等未展开占位。细节只写该画面可见与必要部分，特写不塞不可见鞋履。主定妆照明要能看清身份，叙事关键帧要服务剧情而非摆拍。

## 约束与后期
必须保留的脸/发/衣装/配饰位置/场景布局；人数与动作；本图禁加的装饰或剧情线索；字幕/纸条准确文本后期另列。约束是自然语言，不假定工具支持negative_prompt参数。

## 仅编辑任务填写
主生成与修正另存任务文件；填写真实底图/版本、实际观察或用户指定问题、区域或行列格。头部朝向与眼睛视线分别约束，列不改的其他格；未有底图/问题时只能标条件式预案，不当可执行修正。
底图条件、具体单一区域、唯一修改目标、必须保留项、必要接触阴影/遮挡变化、蒙版状态。未看到成图时仅为修正预案，不能宣称图有错误或已修复。

## 验收
逐项列能在成图观察的标准和明确失败条件；正文完整性、实图目检、用户采用分开记录，不仅写“好看/高清”。
是否符合人物身份/经济/时代、轮廓配色与材质主次、细节可见、空间/动作连贯、参考真实、左右一致、无新增关键设定；实际图片生成后再做目检，本阶段只检查提示词。
